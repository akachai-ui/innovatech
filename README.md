# InnovaTech Solutions Official Website

Official website for **InnovaTech Solutions** — Enterprise Software, Custom Web Applications, Cloud Architecture & UI/UX Design.

## 🚀 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Glassmorphism 3D, Lucide Icons
- **Animation**: CSS Keyframes, 3D Perspective Tilt, Responsive Touch Gestures
- **SEO & Analytics**: OpenGraph Metadata, Google Analytics 4, Meta Pixel

## 🛠️ Getting Started
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
